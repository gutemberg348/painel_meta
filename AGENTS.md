# Preferências de trabalho neste projeto

- O usuário quer que os scripts sejam criados e explicados para ele executar no terminal.
- Só execute testes, consultas de teste à API ou envios de teste quando o usuário pedir explicitamente. Não execute testes automaticamente após alterações.
- Ao entregar scripts, explique o comando, as configurações necessárias, o que ele consulta/altera e como interpretar o resultado.
- Nunca exiba o token FLW ou os segredos do `.env` na saída dos comandos.
